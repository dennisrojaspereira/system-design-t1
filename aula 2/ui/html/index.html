Antes de tudo: quem é você?

Esta tela pertence ao IdP, não à plataforma. Senha, segundo fator, passkey e recuperação de conta moram lá. A plataforma recebe só um token assinado dizendo quem entrou — e decide o que essa pessoa pode ver.

Para ver um IdP de verdade: make idp sobe o Keycloak, e esta tela ganha o botão de login por redirecionamento (OIDC).

Catálogo e busca

A busca roda no Postgres (tsvector + índice GIN, websearch_to_tsquery). Quem decide o play é a API de playback, que confere matrícula e versão ativa na hora.

Upload direto, retomável e privado

Nenhum arquivo escolhido.

O navegador envia cada parte direto ao storage, por uma URL assinada que vale só para aquela parte. A API recebe três chamadas pequenas e nunca vê os bytes do vídeo.
